วิธีคิด

  1. แบ่ง element — วาง node ที่ปลายคาน, ทุก support, ทุกตำแหน่ง point load / moment และขอบของ distributed load แล้วซอยแต่ละช่วงย่อยอีก (ประมาณ L/240) เพื่อใช้วาด deflection แต่ละ node มี 2 DOF คือ v (ขึ้น +) และ θ (ทวนเข็ม +)

  2. Element stiffness (Euler–Bernoulli, EI คงที่, EI = E·I หน่วย kg·cm²):

            EI  ⎡ 12    6h   −12    6h ⎤
k_e  = ──── ⎢ 6h   4h²   −6h   2h² ⎥
        h³  ⎢−12   −6h    12   −6h ⎥
            ⎣ 6h   2h²   −6h   4h² ⎦

  3. Distributed load → equivalent nodal loads (fixed-end forces) แยกเป็นส่วน uniform q₀ กับส่วนสามเหลี่ยม q (0 → q):

    uniform   : [ q₀h/2,  q₀h²/12,  q₀h/2,  −q₀h²/12 ]
triangle  : [ 3qh/20, qh²/30,   7qh/20, −qh²/20  ]

  4. Assemble และใส่ boundary condition — pin / roller: v = 0, fixed: v = θ = 0 แล้วแก้ K·d = F (K เป็น banded matrix กว้าง 4 DOF) ด้วย Hermite element + consistent load ค่าที่ node จะ exact ไม่ใช่ค่าประมาณ

  5. Reactions — R = K·d − F ที่ DOF ที่ถูกยึด ระดับความ indeterminate = จำนวน reaction − 2

  6. Section method — ตัดที่ x แล้วรวมแรงทางซ้ายของหน้าตัด (reactions + loads):

    V(x) = ΣR_y − ΣP − ∫₀ˣ w ds
M(x) = ΣR_y(x−xᵢ) − ΣP(x−xᵢ) − ∫₀ˣ w(s)(x−s) ds + ΣM_cw − ΣM_R,ccw

    ตรวจสอบได้จาก dV/dx = −w และ dM/dx = V · V กระโดดที่ point load / support · M กระโดดที่ applied moment · M สูงสุดเฉพาะที่เกิดตรงจุด V = 0 หรือที่ support

  7. หน่วย — แรง tonf, ระยะ m, w tonf/m, M tonf·m, E ksc (kgf/cm²), I cm⁴ EI = E × I หน่วย kg·cm² (ในการแก้สมการแปลงเป็น tonf·m² = kg·cm² × 10⁻⁷), δ แสดงเป็น cm

  8. หมายเหตุ — ถ้า EI คงที่ทั้งคาน และไม่มี support settlement ค่า reaction, V, M ไม่ขึ้นกับค่า EI (EI มีผลเฉพาะ δ) · pin กับ roller ให้ผลเหมือนกันสำหรับแรงแนวดิ่ง (ไม่คิดแรงตามแกน) · ยังไม่รองรับ internal hinge และ spring support
